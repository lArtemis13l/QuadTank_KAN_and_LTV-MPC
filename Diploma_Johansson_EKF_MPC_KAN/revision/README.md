# Reproducible pipeline for the revised manuscript

Every number, figure and table in the paper is produced by the numbered stage
scripts in this directory. Run them in order from this directory; each writes
into `data/`, `models/`, `results/` and, where relevant, straight into the LaTeX
tree (`../../../els-cas-templates/figs` and `.../tables`).

```bash
python s01_generate_dataset.py     # ~7 min   distillation datasets, both regimes
python s02_train_models.py         # ~20 min  KAN, MLP, DeepONet, polynomial baselines
python s02b_sparsify.py            # ~10 min  term-budget sweep + certified selection
python s03_signflip_analysis.py    # ~2 min   root-cause analysis of the sign anomaly
python s04_stability.py            # ~10 min  certificate, ROA, Monte-Carlo, constraints
python s04b_invariance.py          # ~1 min   checks the structural properties (P1), (P2)
python s05_scenarios.py            # ~10 min  closed-loop scenario campaign
python s06_make_figures.py         # ~1 min   all figures
python s07_make_tables.py          # <1 min   all LaTeX tables
```

## Modules

| File | Contents |
|---|---|
| `qtlib.py` | Plant model, EKF, LTV-MPC, equilibrium map, transmission zeros, LQR, metrics, closed-loop driver |
| `policyform.py` | The deployed controller skeleton `u = sat[u_eq(r) + K e + w(e)·U_max·f(φ)]` and its structural properties |
| `symbolic.py` | Monomial support extraction, design matrices, the shape-constrained convex read-out, operation counting |
| `verify.py` | Closed-loop Jacobian, fixed points, local stability certificate |
| `controllers.py` | Uniform `u = π(x, ref)` interface for every controller compared |

## Design decisions worth knowing

* **Plant parameters** follow Johansson (2000) Table 1. The original notebooks used
  `k = [2.826, 2.961]`, which matched neither the paper's table nor Johansson; the
  revision uses the published values so that code and manuscript agree.

* **References are always reachable equilibria.** With two pumps the equilibrium set is
  two-dimensional, so commanding `(h1, h2)` determines `h3, h4` through
  `qtlib.equilibrium`. The original target `[10, 10, 2, 2]` is not an equilibrium in the
  NMP regime, which is why the cost in the original submission converged to a nonzero
  value and why two of its scenario figures were indistinguishable.

* **Splits are by trajectory/block, never by row**, so no test sample is temporally
  adjacent to a training sample.

* **The KAN contributes only the monomial support.** Coefficients are always
  re-estimated by the convex program in `symbolic.fit_shape_constrained`.

* **`s02b` is idempotent**: it re-derives the KAN support from the stored symbolic
  formulas rather than from its own previous output.

## Scope

Everything in the paper is software-in-the-loop and regenerated by these scripts. The
hardware campaign of the original submission has been dropped: its latency and flash
figures were measured for a different symbolic law and the microcontroller was not
available for re-measurement, so keeping them would have mixed measured and
carried-over numbers. Computational cost is now reported as an exact operation count
(`symbolic.flops` plus `policyform.CORE_FLOPS`), which is a property of the deployed
law rather than of a particular processor.
